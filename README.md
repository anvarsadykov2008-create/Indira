# Галёрка — ИИ-ассистент преподавателя

Веб-интерфейс системы видеоанализа вовлечённости студентов в аудитории.

## Главная идея
Система **не идентифицирует личность и не хранит биометрию**. По кадрам с камеры над доской она определяет только состояние тела:
- 🟢 **Работает** (пишет конспект, смотрит на доску/учителя)
- 🟡 **Отвлечён** (разговаривает, смотрит по сторонам)
- 🔴 **В телефоне** (взгляд опущен на колени / экран)
- 🟣 **Спит** (голова лежит на парте или запрокинута)

Преподаватель видит аудиторию по рядам и местам («Ряд 1, место 5») и сам знает, кто из учеников где сидит.

---

## Что реализовано

1. **Экран «Сегодня»**
   - Карточка идущей или предстоящей пары с вовлечённостью в реальном времени.
   - Расписание на день со статусами и кнопкой старта в 1 клик.
   - Динамика недели (сравнение средних оценок).
   - Автоматические инсайты за 3 недели (когда группа устаёт, где чаще телефоны).

2. **Экран «Наблюдение» (живой режим)**
   - Кадр с камеры с наложением рамок и состояний.
   - Переключатель **«Скрыть лица»** (блюр лиц прямо на лету).
   - Режим **«Карта парт»** (схематичное отображение вместо фото).
   - Фильтрация по состояниям (показывайте только спящих или только телефоны).
   - Интерактивная коррекция: если ИИ ошибся, клик по парте исправляет метку за 1 секунду.
   - Живой накопительный график хода пары с порогом внимания (пунктир).
   - Лента событий с фильтром по длительности (отсекает случайные взгляды в сторону).
   - Горячие клавиши (`Пробел` — пауза, `S` — снимок, `M` — отметка, `B` — блюр).

3. **Экран «Архив пар»**
   - Поиск по группам и предметам, фильтрация по периодам (неделя, месяц, всё).
   - Быстрый просмотр кривой вовлечённости для каждой пары (sparkline).

4. **Экран «Отчёт по паре»**
   - Индекс успешности пары (0–100) с понятным объяснением весов: вовлечённость (50%), устойчивость (25%), дисциплина (25%).
   - Интерактивный таймлайн: наведите курсор — кадр кабинета перемотается на этот момент.
   - Тепловая карта отвлечений по партам.
   - Сравнение с прошлыми парами этой же группы.
   - Экспорт в CSV и версия для печати.

5. **Экран «Кабинеты» и мастер подключения**
   - Список аудиторий, статус камер и пинг.
   - Мастер добавления камеры в 3 шага (IP/RTSP, USB или смартфон на штативе).
   - Рекомендации по установке камеры (над доской, без засвета от окон).

6. **Инструмент «Разметка мест»**
   - Визуальный редактор: перетаскивание рамок поверх кадра из кабинета.
   - Автоматический поиск парт одной кнопкой.
   - Нумерация рядов и мест.

7. **Экран «Настройки» и юридическая безопасность**
   - Генератор официального объявления на дверь кабинета (с кнопкой печати).
   - Политика хранения кадров (по умолчанию «Не хранить»).
   - Настройка порогов срабатывания и чувствительности под каждый тип поведения.
   - Светлая и тёмная темы, автоподстройка под систему.

## Как открыть

Просто откройте файл `index.html` в любом браузере (Chrome, Edge, Firefox, Safari):
- Двойным кликом по `index.html`
- Либо через терминал: `start index.html`
